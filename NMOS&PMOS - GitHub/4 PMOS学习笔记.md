# Whitestar000的 PMOS 学习笔记

## PMOS高侧开关是什么？

* **PMOS高侧开关（High-Side Switch）**，开关放在**负载上方**，通过切断**电源回路**影响主电路。
* 如上所述，**MOS 管导通的条件是「栅极相对于源极」要有足够的电压差**，PMOS 要$$ V_{GS}$$ 为负且绝对值大于阈值。

|                      | 高侧开关（PMOS）            |
| -------------------- | --------------------------- |
| 源极 S 接在哪        | **接电源正极（24V）**       |
| 栅极要拉到哪里才导通 | 拉**低**（比源极低 ≥ 阈值） |

  * 当方波电压为低电平时，NPN管未导通，PMOS管也未接通，电路断开，负载两端没有电压。
  * 当方波电压为高电平时，NPN管被导通，PMOS管接通，电路闭合，负载两端有电压。

  **这里有几个注意事项：**

  1. 分压电阻的配置。

     ​	假设Q2 饱和时集电极≈0.2V，如果没有分压电阻，在V1 高电平、Q2 饱和时，

     ​	$$V_{GS}=0.2V−24V≈−23.8V$$

     ​	这个值**超出了 IRF9321 的 $$V_{GS}(max) = ±20V$$**。Multisim 的模型不会模拟栅氧击穿，但现实中的管子会被直接击穿掉。

     ​	因此，需要添加分压电阻来阻止烧管子。

     $$
     V_{GS}=-23.8V \times \frac{R_{2}}{R_{1}+R_{2}}
     $$
     ​	通过配置两个分压电阻，使得$$V_{GS}$$达到要求值。

  2. 仿真设备的极限。

     ```txt
     ------ 正在为 设计1 - 2026年10月7日, 21:18:57 检查 SPICE 网表------ 
     ======= SPICE 网表检查完毕, 0 错误, 0 警告 ======= 
     Error: Unable to converge during transient analysis. Consider increasing the ABSTOL, VNTOL, and RELTOL options.
     Simulation canceled
     See convergence help for more information
     ```

     ​	**SPICE 网表检查完毕, 0 错误, 0 警告**，这表明网表语法和连线合法。模拟崩掉了，这不是电路错了，是仿真器“算不动了”造成的**瞬态收敛失败**。

     ​	*”R1 越大，栅极节点阻抗越高，PMOS 开关瞬间漏极那个 24V 大摆幅会通过 Cgd（密勒效应）往这个高阻抗节点灌电流，数值求解器在这种节点上最容易步长崩塌。“*

     > 以上斜体是求助AI的结论，我本人完全看不懂……我能理解的内容是：在一瞬间，程序的计算量超过了阈值，所以他崩掉了。

     > 我后来求助长庚的时候，他给我补了一个比喻：
     >
     > *求解器像一个**在黑暗里下楼梯的人**：每迈一步，都要 "站稳了 "才能迈下一步。*

        | 分析选项页 | 绝对电压容差 VNTOL      | 1e-6 → **1e-4**                                              |

* 使用一个推挽电路来让波形变得更“美观”

  ![这有一张图片](photo/PMOS_4.png)

> **推挽电路（Push-Pull Circuit）**是一种由两个参数相同但极性相反的功率开关管*（比如这里 Q4和 Q3，NPN与 PNP晶体管）*组成的对称输出电路。
>
> 两个晶体管交替导通，每个管子只管拉高或者拉低电压中的一件事。
>
> - **“推”（Push）**：一个晶体管负责拉高电压，向负载提供电流，相当于“推”动电流。
> - **“挽”（Pull）**：另一个晶体管负责拉低电压，从负载吸收电流，相当于“挽”回电流。
>
> 两者配合，在负载上合成一个完整的波形。
>
> 这里应用了推挽电路开关速度快的优点，使得PMOS管关断时间改善。

## PMOS高侧开关是怎么工作的

> 三极管由**发射结（B-E）正偏**导通，当基极b与发射极e之间的压差达到一定的门槛后导通，基极电流$$I_{b}$$开始流动，集电极电流$$I_{C}$$被放大。
> $$
> if : \Phi_B - \Phi _E >V_{min} (NPN) \\
> if : \Phi_E - \Phi_B >V_{min} (PNP) \\
> I_E = I_B + I_C
> $$

* 方波电压为高电平时，Q2被导通，$$R_1 R_2$$分压中点处约为12V，栅极区停留在24V左右，使得Q4截止，Q3导通，进而使Q1栅极电压被拉低向12V，PMOS管导通，负载两端有电压。
* 方波电压为低电平时，Q2截止，$$R_1 R_2$$分压中点处来到24V，栅极区停留在12V左右，使得Q4导通，Q3截止，进而使Q1栅极电压被推高向24V，Q1迅速关断，负载两端无电压。

![这有一张图片](photo/PMOS_5.png)

> **栅极**
>
> 栅极上连着的只有三样东西：**Q4 的发射极、Q3 的发射极、Q1 的栅极电容**。既没有电阻接 24V，也没有电阻接地。而 MOS 栅极是绝缘的，直流电流恒为零——所以**没有任何元件能主动把电荷从栅极搬走**。
>
> - 方波跳高，$$R_1 R_2$$分压中点掉到12V，但栅极还停在 24V左右，Q3（PNP）导通，栅极电荷被**往下放**。
> - 当栅极电压降低到12V左右 时 ，$$V_{EB}<0.7V$$  ，Q3自动关断，栅极电压停留在12V左右。
> - 方波跳低，M 回到 24V，Q4（NPN）导通，栅极电荷被**往上充**。
> - 当栅极电压升高到24V左右 时 ，$$V_{EB}<0.7V$$  ，Q4自动关断，栅极电压停留在24V左右。
