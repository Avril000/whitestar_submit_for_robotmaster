# Whitestar000 的 NMOS学习笔记

## NMOS低侧开关是什么？

* **NMOS低侧开关（Low-Side Switch）**，开关放在**负载下方**，通过切断**接地回路**影响主电路。
* **MOS 管导通的条件是「栅极相对于源极」要有足够的电压差**，NMOS 要$$ V_{GS}$$ 为正且大于阈值。

|                      | 低侧开关（NMOS）       |
| -------------------- | ---------------------- |
| 源极 S 接在哪        | **接地（0V）**         |
| 栅极要拉到哪里才导通 | 拉**高**（≥ 阈值即可） |

## NMOS低侧开关是怎么工作的

* 当方波电压为低电平时，NMOS管不导通，电路被断开，此时负载两端没有电压。

* 当方波电压为高电平时，NMOS管被导通，电路连接，此时负载两端有电压。

* 因此，负载两端的电压会是与驱动方波**同频、同相、幅值 24V** 的方波。
